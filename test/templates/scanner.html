How to Use the Scanner

📷 Camera Scan (Recommended)

Standard Mode

This is the primary mode for attendance. Requires a working webcam on the attendance device.

How to use:

  1. Click the "Camera Scan" tab
  2. Click "Start Scanner"
  3. Point the employee's QR code at the camera
  4. Time-in or time-out is recorded automatically

🖼️ File Upload (Backup Mode)

Backup Only

This is not for employee self-service. The attendance operator is responsible for uploading the QR code photo.

When to use this mode:

  • The webcam on the attendance station is not working
  • The camera is broken or unavailable
  • No internet connection (offline mode) — capture photos first, upload them later
  • You need to batch-scan multiple employees (for example, employees who were unable to time-in during the morning)

How to use (step-by-step):

  1. Take a photo of the employee's QR code using a phone or scanner
  2. Transfer the photo to the attendance device via USB, email, Bluetooth, or a shared folder
  3. Click the "File Upload" tab in the scanner
  4. Click the upload area or drag & drop the image file
  5. Click "Scan Uploaded Image"
  6. The QR code is scanned automatically from the image

⏰ Time-In vs. Time-Out

Choose the Right Mode

  • Time-In — Use this when an employee arrives at work in the morning
  • Time-Out — Use this when an employee leaves work at the end of the day

Note: An employee cannot time-in twice on the same day. They must time-in before they can time-out.

⚠️ Common Problems

Camera Not Working?

  • Check browser permissions — allow camera access in the site settings
  • Check if another app is using the camera — close that app first
  • Refresh the page and try again
  • If the camera is completely broken — use File Upload mode as a backup

QR Code Not Scanning?

  • Make sure the photo is clear and not blurry
  • Make sure the QR code is complete (not cut off)
  • If printed — check that it is not smudged or faded
  • If shown on a phone — increase the screen brightness

"Employee Not Found" Error?

  • Make sure the employee is registered in the system
  • Check if the account is active (not deactivated)
  • If a new hire — confirm the account was approved by the admin

💡 Best Practices

  • Lock to Camera mode to avoid confusion — configure this in Admin Settings → QR & Scanner
  • Test the scanner first before deploying it at the actual attendance station
  • Print and laminate the QR codes of all employees so they last longer
  • If a consistent problem occurs — report it to the admin so they can adjust the settings

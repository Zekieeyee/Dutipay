📖 Scanner Modes Explained

Camera Scan (Locked)

Locked to camera scanning only. Switching to file upload is not possible. This is the recommended option for an attendance station with a webcam.

File Upload (Locked)

Locked to file upload only. This is for kiosk mode or when there is no webcam.

Flexible (User can switch)

The user can switch between camera and file upload at any time. This is the default when there is no specific requirement.

🔧 Tools & Requirements

Computer / Laptop

Internet Connection

Power Supply

Stable power source for the attendance station

📖 Installation Instructions

  1. Download the scanner tool file.
  2. Transfer the file to the dedicated attendance device.
  3. Open the file in a web browser (Chrome recommended).
  4. Allow camera access when prompted.
  5. Bookmark the page for easy access.
  6. Place the device at the attendance station.
Note: The scanner tool will continue to work offline once downloaded. However, an internet connection is required to sync attendance records to the server.
